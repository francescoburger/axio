# Moduli futuri

Questa cartella è intenzionalmente priva di implementazioni. La Fase 1 potrà
separare acquisizione IMU e taratura, configurazione, Wi-Fi, OSC, dashboard,
interfaccia fisica ed energia. I pin rimangono in `../hardware_config.h`.
Arduino compila ricorsivamente `src`: aggiungere codice qui solo in una fase
successiva autorizzata. Nessun limite a destinazioni o messaggi è deciso ora.
